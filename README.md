# RiffVault — Local AI Guitar Idea Vault

RiffVault is a local-first AI application for guitarists that solves one specific problem: finding recorded guitar ideas using natural language queries and semantic search.

## Overview
A guitarist records dozens of ideas but often forgets the filenames. With RiffVault, they can import recordings, which are automatically analyzed and stored locally. Later, they can search for "heavy Drop C riffs around 140-150 BPM" or find musically similar ideas.

## Features
- Local-first execution (no mandatory cloud services)
- Open-source/open-weight AI models
- Simple, polished, dark music-oriented UX
